# 幽暗地域暴君：中文卡牌版

这是当前源码副本的非官方中文卡牌版，不是官方中文版，也不会自动修改原作者的在线网站。

## 1. 怎么启动

需要已安装 Node.js（建议 22.12+ 或 24 LTS）。当前项目是网页应用，不是双击 `index.html` 就能运行的独立程序。

**Windows：双击项目根目录的 `start-zh.cmd`。** 首次启动会安装依赖，需要联网；之后会启动本地开发服务器并打开浏览器。保持命令窗口开启；按 `Ctrl+C` 停止服务。此脚本不执行构建、不发布到外网，只监听本机。

也可以在项目根目录手动运行：

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

然后打开终端显示的本地网址（默认 `http://127.0.0.1:5173/?lang=zh-CN`；端口被占用时以终端为准）。

如果地图或英文卡图下载失败，可在项目根目录执行 `npm run preload:images`。它会把地图和 211 张原版卡图预先保存到本机 `assets/` 目录；刷新页面即可继续当前对局。也可以只准备地图：`node scripts/preload-images.mjs --board-only`。好友服可将这些资源上传到自己的服务器，操作见 `docs/friends-server.md`；原版美术的版权归属不变。

脚本根据自身位置定位项目，不包含本机绝对路径或分支名。移动到另一份工作副本时，应保留项目目录结构、`package.json`、`package-lock.json` 及源码；`start-zh.cmd` 必须位于项目根目录。不同副本会各自安装依赖，无需复制 `node_modules`。无预先构建的 `dist` 目录依赖。

如果要更新自己的好友服务器，可双击项目根目录的 `deploy-server.cmd`。
它会完成测试、构建、本机验收、上传重启和公网检查，发布前需输入 `YES` 确认结束当前对局。
首次使用先把 `deploy/settings.example.psd1` 复制为 `deploy/settings.psd1`，
再填写服务器和本机私钥路径；把 `.env.friends.example` 复制为 `.env.friends`。
真实配置已加入 Git 忽略规则，不会上传；详细说明见 `docs/friends-server.md`。

## 2. 第一次玩怎么选

1. 若先看到原版英文介绍页，点击 **Continue** 继续。出现图片下载提示时，点击 **「跳过，直接玩中文版」**，无需下载卡图也能玩。
2. 选择 **2 人**、电脑难度 **简单**，市场牌组选择 **卓尔＋巨龙**。
3. 点击 **开始游戏**。你是 P1，其他玩家由电脑控制。
4. 在地图上点击发光的起始据点，放下第一个部队。找不到地图时点击「地图」，或开启「综合视图」后进入「综合操作」。
5. 页面顶部的 **卡牌图鉴 / 新手帮助** 可随时查看全部卡牌、搜索中文/英文名称、阅读完整效果及基本操作。

本地首页是单人对战 AI。好友服首页提供「与 AI 对战」入口：在当前浏览器对战 1～3 个 AI，每个对手可独立选择随机、简单、标准或困难。计算、存档与归档均在玩家本机，不创建服务器房间，也不上传本地对局日志；真人联机仍使用独立的 2～4 人房号大厅，不允许在线 AI 或 AI 补位。详见 `docs/friends-server.md`。

## 3. 每回合怎么操作

| 界面 | 用途 |
| --- | --- |
| 你的手牌 | 点击一张牌打出；需要目标或选项时，先完成提示 |
| 自动打出基础牌 | 依次打出无需决策的牌；不是自动完成整个回合 |
| 影响力 Influence | 招募市场牌和常备供应牌；招募的牌通常放进弃牌堆，之后洗回牌库 |
| 军力 Power | 每 1 点部署一个部队；每 3 点暗杀一个部队，或遣返一个敌方间谍 |
| 地图 | 先选行动，再点击高亮据点或部队格；大部分行动受势力存在范围限制 |
| 结束回合 | 处理回合结束效果，弃掉已打出与剩余手牌，补到 5 张；未花资源不保留 |
| 撤销 | 仅在允许撤销的本地操作后可用；揭示隐藏牌等操作可能阻断撤销 |

- **晋升 Promote**：把牌移入核心圈，不再参与抽牌循环；终局按核心圈分计分。
- **吞噬 Devour**：将牌移出游戏，通常用于精简牌库或支付效果成本。
- **取代 Supplant**：暗杀目标部队，再在原格部署自己的部队。
- **遣返 Return**：把棋子退回其所属玩家的储备，不计入战利品。
- **专注 Focus**：展示另一张同阵营手牌来触发奖励；展示的牌仍留在手中。
- **控制 / 完全控制**：据点内拥有严格最多部队可控制；占满所有部队格且无敌方间谍才完全控制。

任一玩家的兵营部队耗尽，或市场牌库耗尽，会触发最后一轮。终局综合计算据点、完全控制、战利品、牌库分、核心圈分和胜利点，以程序结算为准。

## 4. 汉化覆盖与边界

- 覆盖当前 `assets/card-data.json` 中 **211 条卡牌记录、125 种不同卡牌**。
- 包含基础供应牌及卓尔、巨龙、元素、恶魔、异怪、亡灵六种市场半牌组。
- 卡名、阵营、种族、效果、主要开局选项、核心行动按钮及常见卡牌选择提示已翻译。
- 开启图像时显示原版卡图，中文卡名与效果放在卡图下方；关闭时使用中文文字卡面。悬停可放大，图鉴提供正常字号的完整说明。
- 页顶可切换 English；语言偏好保存在浏览器中。URL 的 `?lang=zh-CN` 或 `?lang=en` 可覆盖偏好；切换语言不会重开对局。
- **不是全界面百分百汉化**：部分游戏日志、复杂动态提示、地图地名、联机大厅、报错与开发调试页仍保留英文。未知提示会回退英文，不会隐藏。
- 没有重绘或翻译原版英文卡图上的文字。中文译文保留在卡图下方。自有服务器版使用同源压缩 WebP：本地 AI 或真人对局开始前，必须完整下载到当前浏览器（整包约 12.6 MB，可停止后继续），或选择无图模式。对局中不在线补图，缺失缓存显示文字卡牌或可操作的示意地图；「图片设置」可切换，联机仍需网络。
- 译文是参考当前项目卡牌数据与效果实现的非官方说明，不保证采用官方中文术语，也不修正原项目已有规则差异。原始规则标识、牌名字段、效果处理器和存档格式保持不变。

## 5. 后续维护与验证

新增玩家文本统一写入 `src/i18n.ts` 的 StringTable。中文卡牌按 `effectKey` 映射，勿直接翻译引擎里的英文牌名，否则可能破坏效果查找、AI 或存档兼容性。

检查译文覆盖与卡面输出：

```powershell
npm run test:zh
npm run test:card-data
```

建议手动验证：开新局、选择起始据点、打出贵族/士兵、招募、部署、结束回合、晋升/吞噬、打开图鉴搜索、对局中切换中英并确认手牌和资源不变、刷新继续存档。扩展牌组还应分别验证专注、吞噬自身与核心圈效果。

**本次修改不自动运行编译或构建。** 本地版正式产物使用 `npm run build`，随后 `npm run preview`；好友服使用 `npm run build:friends`，完整发布与验收流程见 `docs/server-redeploy-agent.md`。
